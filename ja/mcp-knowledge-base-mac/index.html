読み取り専用MCP知識アクセス

互換性のあるAIアプリが、Mac全体ではなく、パックを検索するようにします。

MCPは、アプリケーション間の標準接続です。SourceShelfは、それを使用して、保存された知識パックを読み取り専用ローカルスナップショットとして公開し、互換性のあるAIクライアントが検索して読み取ることができます。

  • 書き込みツールなし

選択したパックの認証、検索、および取り消し

動画の内容

焦点を当てたパッケージを保存し、最新の信頼性と安全性の結果を確認し、ローカルAIアクセスを承認します。

ローカル構成をコピーして、パーソナルファイルシステムパスを露呈せずに互換性のあるデスクトップAIクライアントに保存します。

クライアントは承認されたスナップショットを検索し、そのパックから制限された、許可されたテキストリソースのみを読み込みます。

個々の共有を停止するか、ローカルAIアクセスを無効にして、コピーされた構成をすぐに無効にします。

専門用語を使わないMCP

互換性のあるAIアプリケーションは、時々他のアプリケーションから情報を要求する方法が必要です。Model Context Protocolはその接続を提供します。

SourceShelfを使用すると、保存したパックを選択し、ローカルAIアクセスを許可できます。その後、AIクライアントはSourceShelfに関連する文章を探し、そのパックから承認されたテキストリソースを読み取るように依頼できます。

理解できるパック境界

SourceShelfは、ライブライブラリを公開したり、クライアントに一般的なファイルシステムツールを提供したりしません。選択したパックの不変のコピーをランダムな認証識別子の下に作成します。

スナップショットには、コピーされたMarkdown、参照されたローカルイメージ、カタログ、チェックサム、および許可リストが含まれています。元のパス、出力フォルダパス、セキュリティブックマーク、およびパッケージ外のすべてのライブラリソースは除外されます。

まず検索し、必要なものだけを読んでください。

互換性のあるクライアントは最初にSourceShelfに、承認済みのパッケージ内の関連する文章を探すように要求します。その後、すべてのドキュメントを一括読み込むのではなく、制限されたページで承認済みのテキストソースを読み取ることができます。

高度なMCPの詳細

正確な読み取り専用ツールと接続境界を確認してください
  • search_packは、承認されたパッケージ内の関連する構造認識パッセージを見つけます。
  • read_pack_resourceは、境界付きページで許可されたテキストソースを読み込みます。
  • このヘルパーは、プロンプト、サブスクリプション、書き込みツール、任意のパス、リモート取得、またはネットワークリスナーを提供しません。
  • 互換性のあるAIクライアントはローカルでヘルパーを起動し、SourceShelfはすべてのリクエストに対して認証情報を再読み込みします。

書き込みアクセス権がなく、ネットワークサーバーもありません。

SourceShelf MCPヘルパーは、ソースを編集したり、ファイルを削除したり、リモートコンテンツを取得したり、任意のパスをブラウズしたり、ネットワーク接続を監視したりすることはできません。 互換性のあるAIクライアントによって起動されたコマンドを介してローカルで通信します。

共有を停止したり、MCPを無効にしたりすると、コピーされた構成はすぐに無効になります。

ローカルまたはクラウドベースのモデルは、あなたの選択のままです。

MCPは、デスクトップのAIクライアントとSourceShelfを接続します。クライアントは、Mac上で実行されているモデルまたはクラウドベースのモデルを使用できます。

SourceShelfはローカル知識接続を制御しますが、選択したサードパーティのAIクライアントのプライバシーポリシーやデータ処理は制御しません。

仕組み

ソースから有用なコンテキストへの明確なワークフロー

  1. 1

    パックを保存する

    読みやすいソースの焦点を絞ったコレクションを作成して保存します。

  2. 2

    ローカルAIへのアクセスを承認する

    信頼性と安全性の結果を確認し、読み取り専用のスナップショットをパブリッシュします。

  3. 3

    互換性のあるクライアントを設定する

    構成またはローカルコマンドをクライアントにコピーします。

  4. 4

    検索と取り消し

    クライアントに選択したパッケージを検索してもらい、アクセスが不要になったら共有を停止します。

よくある質問

始める前に知っておくべきこと

MCPは何を意味しますか？

Model Context Protocolは、互換性のあるアプリケーションが他のアプリケーションからコンテキストとツールを要求するための標準方法です。SourceShelfは、認証済みの知識パックへのローカル、読み取り専用アクセスをするためにそれを使用します。

MCPは、私のMac全体にAIへのアクセスを許可しますか？

いいえ。SourceShelfは、あなたが承認した保存されたパックの不変のスナップショットのみを露出します。

AIは私の書類を変更できますか？

いいえ。SourceShelfにはMCPの書き込み、削除、または任意のファイルのツールは提供されていません。

クラウドベースのAIクライアントは接続を使用できますか？

潜在的には、そのデスクトップアプリケーションが必要なローカルMCP接続をサポートする場合。サードパーティクライアント自身のプライバシーとデータ処理条件は引き続き適用されます。

アクセスを取り消すにはどうすればよいですか？

個々のパッケージ共有を停止するか、SourceShelfでローカルAIアクセスを無効にします。ヘルパーはすべてのリクエストに対して認証情報を再読み込みするため、取り消されたアクセスはすぐに機能しなくなります。
