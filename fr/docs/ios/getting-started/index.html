Premiers pas sur iPhone et iPad

SourceShelf 1.0.2 conserve une bibliothèque de recherche privée et interrogeable sur votre appareil. L’app peut capturer des pages Safari autorisées, importer des documents locaux compatibles, organiser les sources en packs, lire le contenu enregistré hors ligne et exporter des packs complets avec la feuille de partage du système.

Comprendre l’espace de travail #

SourceShelf utilise la même hiérarchie sur tous les écrans :

  1. Bibliothèque contient Toutes les recherches, Favoris et vos packs enregistrés.
  2. Sources affiche les recherches de la bibliothèque ou du pack sélectionné.
  3. Lecteur affiche la source sélectionnée et ses images archivées localement.

Sur iPad, ces éléments peuvent apparaître dans un espace à trois colonnes Packs → Sources → Lecteur. Sur iPhone ou dans une fenêtre iPad étroite, la même hiérarchie devient une suite d’écrans. Utilisez les commandes de navigation pour revenir au niveau précédent.

Ajouter vos premières recherches #

Choisissez l’une de ces méthodes :

  • Dans SourceShelf, ouvrez le menu Plus de la barre latérale et choisissez Importer des recherches… pour sélectionner un ou plusieurs fichiers compatibles dans Fichiers.
  • Dans une autre app, utilisez Partager et choisissez SourceShelf pour un document PDF, image, RTF, Markdown ou texte compatible.
  • Dans Safari, activez l’extension SourceShelf pour capturer une page, capturer des onglets sélectionnés dans la fenêtre active ou importer la collection llms.txt d’un site.

Les sources importées ou capturées apparaissent dans Toutes les recherches. L’importation de plusieurs sources depuis Safari ou depuis un pack portable peut aussi créer ou compléter un pack nommé.

Rechercher et organiser les sources #

Utilisez Rechercher dans les recherches pour interroger localement le contenu enregistré. Le menu Filtrer peut limiter la vue actuelle par disponibilité ou type d’acquisition, et le menu de tri modifie l’ordre visible. Balayez une source ou utilisez ses actions pour l’ajouter aux favoris ou à un pack, la retirer du pack actuel ou la supprimer de la Bibliothèque.

Retirer une source d’un pack la conserve dans Toutes les recherches. La supprimer de la Bibliothèque supprime cette source locale et ses appartenances aux packs. Supprimer un pack ne supprime que le pack ; ses sources et ressources archivées restent dans Toutes les recherches.

Lire hors ligne #

Sélectionnez une source pour l’ouvrir dans le Lecteur. SourceShelf affiche le Markdown stocké localement, les liens sûrs, les listes, le code et les images archivées. Les images distantes ne sont pas chargées automatiquement. Une source enregistrée et ses images archivées restent disponibles sans connexion.

Déplacer des recherches vers un autre appareil #

Ouvrez un pack, choisissez Plus > Exporter le pack…, sélectionnez un format portable, puis utilisez la feuille de partage pour enregistrer dans Fichiers, utiliser AirDrop ou transmettre le fichier à une autre app. Sur l’appareil de destination, choisissez Importer des recherches… et sélectionnez le pack.

SourceShelf ne propose pas de synchronisation dans le nuage. Un pack ne se déplace que lorsque vous l’importez, l’exportez, l’envoyez par AirDrop ou le partagez explicitement.

Différences entre les plateformes #

L’app iPhone et iPad se concentre sur la capture, l’importation locale de documents, la recherche, la lecture, l’organisation et les packs portables. L’importation de dossiers, la conversion Office, les dossiers de sortie Mac, l’automatisation avec Raccourcis, les rapports de confiance et de sécurité, la comparaison des packs évolutifs, les outils de maintenance du stockage et l’accès local à l’IA par MCP restent réservés au Mac dans la version 1.0.2.

Continuez avec la capture Safari, l’importation et la lecture de documents, les packs et la portabilité ou les réglages et la confidentialité.
