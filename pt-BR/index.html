O que ele faz

Um só lugar para suas fontes, imagens e pacotes prontos para IA.

Capture, converta, pesquise, valide e empacote arquivos de origem locais sem enviar seu trabalho para um serviço de conversão em nuvem.

01

Salvar fontes como Markdown local

Capture páginas da web, arquivos e pastas como Markdown limpo com metadados de origem preservados.

02

Capturar conteúdo da web no Safari

Salve páginas completas, conteúdo principal, texto selecionado ou áreas visíveis da página diretamente do Safari, incluindo imagens localizadas no navegador que o Safari pode acessar durante a captura.

03

Importar pastas e documentação

Converta pastas inteiras de PDFs, arquivos do Office, imagens, HTML, texto, Markdown e sites de documentação exportados.

04

Itens recentes com busca e filtros

Encontre as fontes certas rapidamente, mesmo quando seu arquivo local cresce.

05

Exportar pacotes de conhecimento para IA

Transforme capturas e documentos selecionados em exportações ZIP estruturadas, incluindo pacotes compatíveis com OKF com páginas Markdown, metadados e um índice.

06

OCR para PDFs digitalizados

O OCR digitaliza PDFs e imagens localmente no seu Mac.

07

Markdown gerado com seus recursos

Markdown legível com metadados de origem preservados, além de imagens salvas em pastas sidecar claras como Page Name.assets.

08

Privado desde a concepção

Capturas, ativos, verificações de pacotes, limpeza e exportações acontecem localmente no seu Mac sem processamento em nuvem ou telemetria.

09

Atalhos / Automação

Automatize a conversão de Markdown com Atalhos da Apple.

Pacotes de referência para IA

Confira o que está pronto antes de exportar.

O Pack Health ajuda você a entender o que será agrupado, o que precisa de atenção e o que permanece vinculado antes de criar um pacote de conhecimento reutilizável ou uma exportação compatível com OKF.

Status de preparação do pacote

  • Veja se o conteúdo selecionado está pronto, tem avisos ou precisa de atenção.
  • Identifique a falta de Markdown, links de imagens locais quebrados, imagens arquivadas ausentes e nomes de páginas duplicados com antecedência.

Conteúdo claro do pacote

  • Cada fonte selecionada se torna sua própria página Markdown para fácil navegação e reutilização.
  • Exportar ZIPs de pacotes compatíveis com OKF com base no Google's Open Knowledge Format (OKF) especificação.
  • Imagens remotas, mídia salta e documentos vinculados são chamados quando permanecem como links em vez de arquivos agrupados.

As imagens acompanham o conteúdo

Capturas de tela da web, diagramas, imagens incorporadas e imagens locais do navegador de aplicativos autenticados como o Confluence podem viajar com o Markdown capturado quando o Safari pode acessá-los.

Arquivos de longo prazo mais seguros

As imagens são propriedade do registro do item SourceShelf, portanto, mover ou excluir um arquivo Markdown exportado não destrói automaticamente os ativos arquivados.

Detalhes

Criado para pastas de fontes reais, com limites claramente indicados.

Entradas compatíveis

  • Capturas do Safari
  • PDFs com texto selecionável
  • PDFs digitalizados via OCR local
  • TXT
  • Markdown
  • HTML
  • Pastas de documentação HTML exportadas
  • Exportações HTML no estilo Confluence
  • RTF
  • PNG
  • JPEG
  • TIFF
  • HEIC/HEIF where supported
  • DOCX
  • PPTX
  • XLSX
  • Pastas contendo arquivos suportados

Limitações atuais

  • Arquivos antigos do Office .doc, .ppt, .xls não são compatíveis atualmente.
  • OCR é o melhor esforço.
  • O layout complexo do documento pode não ser preservado perfeitamente.
  • O espelhamento da estrutura de pastas e a observação de pastas não estão atualmente incluídos.
