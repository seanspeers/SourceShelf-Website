# SourceShelfを使い始める

この手順では、いくつかのファイルを変換し、順序付けされたパックを作成し、それをチェックし、エクスポートします。

## 1. 出力フォルダを選択する

開いている **ソースシェルフ > 設定 > 一般** および出力フォルダを選択します。変換されたMarkdownはそこに保存されます。SourceShelfはフォルダのアクセス情報を記憶するため、後で変換を行うときに別のプロンプトなしで使用できます。

認識しやすく、バックアップしやすいフォルダを選択してください。SourceShelfは、ローカルライブラリのメタデータと管理された資産もアプリコンテナに保持しています。出力フォルダの変更は、古いMarkdownファイルを移動しません。

## 2. ファイルを変換する

開いている **改宗する**、その後、ファイルをドロップエリアにドラッグするか、選択します。 **ファイルを選択する**. あなたはまた使用することができます **ファイル>開く**、フォルダ全体を変換するか、ローカルをインポートします。 `llms.txt` コレクション。

![ローカルファイルに対応した変換ワークスペース](../../assets/images/convert.png)

各成功したコンバージョンにより、以下が生成されます。

- 出力フォルダのMarkdownファイル。
- タイトル、ソースタイプ、日付、利用可能性を含むライブラリエントリ。
- プレビュー、チャンキング、比較に使用される管理された意味的メタデータ。
- ソースフォーマットまたはキャプチャにサポートされている画像が含まれている場合、アーカイブされた資産。

元のファイルは変更されません。

## 3. ライブラリを確認する

開いている **ライブラリ**。新しく変換されたアイテムは、日付でグループ化すると上に表示されます。アイテムを選択してインスペクタを開きます。 使う **プレビュー** レンダリングされたコンテンツと **マークダウンソース** YAMLの前文を含む正確な保存されたMarkdownについては。

![ライブラリ内の合成デモソース](../../assets/images/library.png)

ライブラリフィルターは、表示される内容のみに影響を与えます。現在のパックは変更されません。

## 4. パックを作成する

開いている **パック**、選ぶ **新しいパック**、そして左側のソースブラウザを使用して資料を探します。個々のソースを追加するか、使用してください。

- **マッチングを追加する** 現在のフィルターの場合。
- **すべてエクスポート可能なものを追加する** 読み取り可能なライブラリアイテムごとに。
- **最後にエクスポートしてから追加する** 最後の成功したエクスポート後にキャプチャまたは変換されたアイテムの場合。

アイテムをドラッグするか、を使用して、中央リストを再順序します。 **上がる** そして **下がる**。表示された順序は、エクスポート順序となり、ローカルAIアクセスを通じて提示された順序となります。

パックを保存して耐久性のある名前を与え、ライブパック比較を有効にします。 `llms.txt` フォルダ生成、および MCP 共有する。

![合成市販研究ファイルから作られたオーダーパック](../../assets/images/pack-builder.png)

## 5. 信頼性と安全性を実行する

選択する **信頼性と安全性**. SourceShelfは、ソースの読みやすさ、名前付け、パッケージ構造、変更日、ウェブソースの年齢、アセット参照、コンテンツハッシュ、およびプロンプト注入言語を示している可能性のある保守的なパターンをチェックします。

警告は勧告です。SourceShelfは元のコンテンツを保存し、それを信頼できない参照資料としてラベル付けします。それはそれを消毒していると主張するものではありません。

## 6. エクスポート

選択する **エクスポート...**、次にワークフローに一致する目的地に選択します。

- **AI リファレンスパック ZIP** AIチャット、エージェント、プロジェクトワークスペース用。
- **OKF v0.2 バンドル ZIP** 標準ベースのカタログとエージェント用。
- **マークダウンコンテキストパック** 1つのポータブルファイルの場合；
- **llms.txt コレクションフォルダ** 順序済みの、検査可能なフォルダの場合。
- **結合マークダウンをコピーする** 素早く貼り付けるために。

![SourceShelfの5つのエクスポートオプション](../../assets/images/export-chooser.png)

ZIPと `llms.txt` フォルダエクスポートは、新しいTrust & Safetyチェックを実行します。Markdownとクリップボードエクスポートはすぐに開始されます。成功したエクスポートは、次のためのローカルベースラインを記録します。 **更新＆比較**。
