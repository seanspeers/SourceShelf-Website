信頼性と安全性、継続運用パック

Trust & Safetyは、パッケージがSourceShelfから送信されたり、別のローカルアプリケーションで使用できるようになったりする前に、パッケージを検査するのに役立ちます。これは、コンテンツが安全であることを保証するものではなく、ガイダンスレポートです。

SourceShelfがチェックする内容 #

レポートには、次のチェックが含まれています。

  • 読み取り可能で利用できないソース。
  • 未解決の保存済みパッケージ参照。
  • 出力サイズとアーカイブされた画像の個数。
  • 命名、衝突、およびパッケージ構造；
  • ソースとパッケージ化されたファイルのチェックサム。
  • 修正日；
  • 適用されるステレンシーポリシーよりも古いウェブキャプチャ。
  • 無効な資産とリンク参照。
  • 指示のオーバーライド、システムプロンプトによる開示、ツールの使用、資格情報、またはエクフィレーション言語の可能性。

リスク検出器は意図的に保守的です。調査結果によると、カテゴリ、マークダウン行、および短い抜粋が示されています。フェンス付きコード内の例では、可能な限り深刻度が軽減または抑制されます。

信頼できない参照コンテンツ #

キャプチャされた変換された素材は、以下のように分類されます。 untrusted_reference. 生成されたコンテキスト文書と MCP 読み込みには、目に見える通知が含まれています。SourceShelfは元の本文を保持するため、レビューできます。指示は削除されず、資料は消毒されたものとして説明されません。

準備、警告、およびエラー #

  • 用意ができて 共有された構造チェックが通過し、勧告事項のレビューが必要ないことを意味します。
  • 警告 レポートを確認した後、エクスポートまたは共有を許可します。
  • 読み取り可能なソースのエラー まだ明示的な「問題がある場合」の継続を許可する場合があります。
  • 読み取り可能なソースはありません 提供すべき有益な情報が何もなかったため、エクスポートや共有をブロックします。

構造的エクスポート検証は依然として権威的であり続けます。パッケージ検証に失敗した場合、SourceShelfは無効な結果を書き込みません。

錆び #

ウェブキャプチャは、グローバルデフォルトの年齢が90日を使用します。キャプチャレシピは、その値を継承したり、正の数の日を選択したり、キャプチャの年齢に基づく期限切れを無効にしたりできます。

ファイル変換は、任意の年齢しきい値ではなく、変更日とコンテンツハッシュを通じて比較されます。SourceShelfは決して取得しません URL ウェブページが変更されたかどうかを判断するために。

更新＆比較 #

エクスポートが成功した後、SourceShelfは保存されたパックのベースラインを保存します。 選択する 更新＆比較 現在のローカルステータスを分類するために：

  • 新しい —現在のパック内にあるが、ベースラインには含まれていない。
  • 変化した — 意味的なコンテンツまたは追跡された原産地メタデータが異なる。
  • 欠けている —参照されているが、現在読み込めないか使用できない。
  • 変化していない — コンテンツとトラッキングされたメタデータハッシュが一致します。
  • 離れて — エクスポート時に存在しますが、保存されたパックにはもはや存在しません。

順序の変更は別途報告されます。詳細シートには、現在の日付と最後にエクスポートされた日付、および短縮されたハッシュが表示されます。一致するコンテンツとメタデータのハッシュは、変更なしと分類されます。

無題のパックには永続的なベースラインはありません。まずパックを保存してください。キャンセルまたはエクスポートエラーはベースラインを更新しません。エクスポートが成功してもベースラインの永続性が失敗した場合、SourceShelfはパックを現在のものとして主張する代わりにトラッキングエラーを報告します。

レポートが古くなる場合 #

メンバーシップ、順序、アクティブパック、ソースステート、レシピポリシー、ベースラインの変更により、以前のTrust & Safetyまたは比較結果が無効になります。これを信頼する前に、再度チェックを実行してください。
