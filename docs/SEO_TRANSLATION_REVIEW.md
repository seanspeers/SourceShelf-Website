# SourceShelf Landing Page Translation Review

The new public translations are machine-generated drafts. A fluent reviewer must verify benefit-first phrasing, product terminology, claims, metadata, screenshot alt text, planned transcripts, FAQs, related links, and App Store CTA labels. Preserved terms include SourceShelf, Markdown, MCP, Model Context Protocol, llms.txt, RAG, OKF, and protocol tool names.

Checking a page means reviewing every new public string for that route, not only the headline.
