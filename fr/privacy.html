Politique de confidentialité

SourceShelf est conçu comme une application Mac locale. L’app traite les captures, les conversions, les ressources archivées, les vérifications de packs, le nettoyage et les exportations sur votre Mac, et n’utilise ni conversion dans le cloud, ni analyse dans l’app, ni télémétrie, ni compte, ni API de conversion externe.

Ce qui reste local

  • Captures Safari
  • Conversions de fichiers/dossiers
  • Importations du site de documentation
  • OCR du PDF et de l'image numérisés à l'aide de l'Apple Vision local.
  • Génération de packs de contexte et de paquets compatibles avec OKF
  • Paquet de contrôles de santé pour les paquets de référence IA
  • Actifs web archivés et dossiers d'images de sidecar
  • Utilisation du stockage local et nettoyage des actifs orphelins
  • Histoire récente
  • Sélections/collections enregistrées
  • Queue de transfert de Safari

Emplacement des fichiers

Les fichiers Markdown générés sont enregistrés dans le dossier de sortie sélectionné par l'utilisateur. Les images capturées peuvent être enregistrées avec Markdown dans des dossiers sidecar lisibles tels que Page Name.assets. Reference Pack ZIPs, ZIPs de paquets compatibles OKF et Context Packs sont enregistrés ou copiés là où l'utilisateur le souhaite. L'historique de l'application, les paramètres, les sélections enregistrées et les actifs web archivés sont stockés localement dans le conteneur application/app-group.

Les images sont suivies par le fichier d'enregistrement de l'élément SourceShelf, donc le déplacement ou la suppression d'un fichier Markdown exporté ne détruit pas automatiquement les actifs archivés.

Stockage local et nettoyage

La page de confidentialité locale explique les actifs web archivés, montre l'utilisation du stockage local et offre un nettoyage minutieux uniquement pour les fichiers véritablement orphelins. Le nettoyage est conçu pour éviter de supprimer les actifs toujours détenus par une entrée de SourceShelf.

Ce que SourceShelf ne fait pas

  • Aucune télémétrie dans l’app
  • Aucune analyse dans l’app
  • Pas de cloud OCR
  • Pas de conversion en nuage
  • Pas d'API de conversion externe
  • Aucune compte n'est requise.

Après l’exportation

Les fichiers Markdown exportés, les dossiers d'actifs sidecar, les packs contextuels, les ZIP des packs de référence IA et les ZIP des paquets compatibles OKF sont des fichiers normaux. Vous contrôlez où vous les enregistrez, les copiez, les téléchargez ou les partagez.

Confidentialité du site Web

L’app SourceShelf reste dépourvue d’analyse et n’envoie aucune télémétrie.

Sur ce site Web, Google Analytics est désactivé sauf si vous choisissez Autoriser l’analyse. Avant votre consentement, le script Google Analytics n’est pas chargé et aucune donnée d’analyse n’est envoyée à Google.

Si vous l’autorisez, Google Analytics utilise des cookies propriétaires pour mesurer les visites de pages, les défilements, les téléchargements, les clics sur des liens sortants et d’autres interactions avec le site. Les fonctionnalités publicitaires et les signaux Google sont désactivés.

Vous pouvez modifier votre choix à tout moment à l’aide de Paramètres d’analyse dans le pied de page.

Découvrez comment Google utilise les informations provenant de sites ou d’applications qui utilisent ses services.

SourceShelf stocke vos choix de thème, de langue et d’analyse localement dans votre navigateur. Les préférences de thème et de langue ne sont pas utilisées à des fins de suivi ni envoyées à SourceShelf.

Les vidéos YouTube facultatives utilisent des lecteurs à confidentialité renforcée qui ne se chargent qu’après un clic. Aucun lecteur YouTube n’est chargé et aucune connexion à YouTube n’est établie tant que vous ne choisissez pas de lire une vidéo. Si vous lisez ou ouvrez une vidéo, Google peut traiter des données conformément à sa politique de confidentialité.

Ce site Web n’utilise aucun pixel publicitaire ni aucune police ou CDN externe. GitHub Pages ou les fournisseurs de DNS ou d’hébergement peuvent traiter les journaux de serveur ordinaires dans le cadre de l’hébergement.

Pour des questions de confidentialité, envoyez un e-mail support@sourceshelf.app.
