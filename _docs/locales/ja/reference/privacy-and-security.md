# プライバシーとセキュリティ

SourceShelfはデフォルトでローカルです。ファイルの変換、OCR、ウェブキャプチャ処理、意味解析、プレビュー、リクエストチャンクング、信頼性とセキュリティ、チェックサム、エクスポート、 `llms.txt` インポート、継続運用パック比較、そして MCP このMacで検索/読み込みを実行します。

## ネットワークなし保証

SourceShelfは次の期間中にリモートコンテンツを取得しません。

- ファイルの変換またはプレビュー；
- `llms.txt` インポートまたは生成；
- 更新＆比較；
- MCP リソースのリスト、検索、または読み込み；
- バケット生成。

Safariのキャプチャは、有効になっている拡張機能を通じて、すでに表示しているページからコンテンツを受け取ります。 リモコン URL地元で見つかりました `llms.txt` 取得されるのではなく、使用できない参照として保持されます。

## SourceShelfが保存しているもの

使用する機能に応じて、ローカルストレージには次のものが含まれます。

- 出力フォルダ内のMarkdownを変換しました。
- ライブラリの履歴と保存済みパック。
- ドラフトメタデータの順序；
- 意味的ドキュメントキャッシュ；
- アーカイブされたウェブ画像；
- レシピをキャプチャし、キューに並んだレビューのドラフトを保存します。
- 成功したエクスポート基準線；
- 明示的に承認された MCP スナップショット。

ドラフトスナップショットとベースラインには、任意のマークダウンコンテンツのコピーではなく、識別子、順序、日付、ハッシュが保存されます。 MCP スナップショットは意図的に共有パックの読み取り可能なMarkdownと参照されたアセットのみをコピーするため、サンドボックス化されたヘルパーは幅広いファイルアクセスを必要としません。

ライブラリレコードは、削除するまで保持されます。 **設定 > 一般 > ストレージの確認…** 生成されたソースデータの削除から、安全で再生可能なクリーニングを分離します。ユーザーが表示できる生成された出力はゴミ箱に移動され、スター付きおよび保存パックソースはデフォルトで保護され、元のインポートされたドキュメントは選択または削除されません。 見てみる [SourceShelfストレージを管理する](../guides/storage-management.md) クリーニングワークフローのために。

## ローカルパスプライバシー

このアプリは独自のインスペクタでローカルパスを表示するため、ファイルを開いたり表示したりできます。ファイルソースパスは、エクスポートされた原産地、OKF概念、マニフェストから除外されます。 `llms.txt` 出力、そして MCP スナップショット。スクリーンショットドキュメントも同様に、これらのローカル専用詳細をトリミングまたはマスクする必要があります。

## 信頼分類

キャプチャされた変換されたテキストはマークされています。 `untrusted_reference`。信頼性と安全に関する警告はガイダンスであり、その資料が消毒されたことを決して主張するものではありません。その中に含まれる指示に従う前に、ソーステキストを確認してください。

## MCP 境界線

MCP 共有とは：

- デフォルトで無効化されています。
- 保存されたパックごとに承認されます。
- ネットワークリスナーがない署名済みのローカルstdioヘルパーによって提供されます。
- 読み取り専用；
- 許可リストによって制限され、そして SHA-256 検証；
- すぐに取り消すことができます。

この2つのツールはスナップショットを検索し、許可リストに載っているリソースを読み取ります。ファイルシステムパスツール、一般的なファイルブラウザ、書き込みアクション、リモート検索、プロンプト、またはサブスクリプションはありません。

## IDと構成を共有する

共有IDは、1つのローカルスナップショットを承認します。公開リポジトリやドキュメントのスクリーンショットから離してください。SourceShelfを移動、再インストール、または更新した場合、ヘルパーパスを再コピーしてください。クライアント構成を削除するだけで頼るのではなく、SourceShelfからのアクセスを取り消してください。

製品のプライバシーに関する声明については、[SourceShelfプライバシーポリシー](/ja/privacy.html)をご覧ください。
