# 用語集

**アーカイブされた資産**  
サポートされているキャプチャまたは変換からSourceShelf管理のローカルストレージにコピーされた画像。エクスポートには、選択された読み取り可能なMarkdownによって参照されるアセットのみが含まれます。

**ベースライン**  
パックの配信が成功した後に保存されたハッシュ、メタデータ、日付、形式、ソースID、およびソートは、「その後」状態として使用されます。更新して比較はそれを使用します。

**レシピをキャプチャする**  
ターゲットテンプレート、YAML、コンテンツモード、画像/リンクの動作、レビュー、ドメインルール、および期限切れのための再利用可能なSafariキャプチャポリシー。

**ライブラリ**  
変換されたソースとキャプチャされたソースを検索できるブラウザです。これは現在のパックではありません。

**継続運用パック**  
ローカルソースを新しい、変更された、欠落した、変更されていない、または削除されたに分類できる、正常にエクスポートされたベースラインを持つ保存済みパック。

**ローカルAIアクセス**  
SourceShelfのオプトイン MCP 保存したパックのワークフローを共有する。

**MCP**  
モデルコンテキストプロトコルは、AIホストがサーバーからリソースやツールを検索できる標準です。SourceShelfはローカルstdioのみを使用します。

**OKF**  
オープン知識フォーマット。SourceShelfは、SourceShelfマニフェスト拡張機能を使用して、正規のv0.2概念メタデータをエクスポートします。

**パック**

ライブラリのソースIDを順序付きで選んだものです。保存済みパックはすべてのプラットフォームで書き出せます。バージョン1.0.2では、比較とローカルAIアクセスはMac専用です。

**ポータブルパック**

順序付きの正規Markdown、安全な来歴、参照されるアーカイブアセット、バージョン付きSourceShelfマニフェストを含むZIPリサーチパッケージです。各デバイスの非公開ライブラリ構造を公開することなく、Mac、iPhone、iPadのSourceShelf間で手動で移動できます。

**レシピレビュー**  
保存する前にキャプチャした Markdown と目的地のメタデータを編集できるオプションのキュー化された手順です。

**リテラブルチャンク**  
に記録されたソースの境界付き、構造認識可能なセクション `chunks.jsonl` 安定したID、原産地、ハッシュ、ヘッダー、および推定トークン数が付いています。エンベディングではありません。

**意味的な文書**  
SourceShelfのヘッダー、段落、リスト、表、コード、画像、キャプション、ページ境界、引用符、およびフォールバックコンテンツのバージョン付きローカル表現。

**共有ID**  
公開されているものを識別するランダムなローカル認証 MCP スナップショット。

**スナップショット**  
不変で、パッケージ範囲内の MCP 読みやすいMarkdownのコピー、参照資産、カタログ、 `llms.txt`、チェックサム、および許可リスト。

**信頼性と安全性**  
読みやすさ、パッケージング、新鮮さ、チェックサム、資産、および保守的な非信頼性のある指示パターンのための事前飛行レポートです。これは消毒ではなく、ガイダンスです。

**信頼できない参照**  
キャプチャされたおよび変換された素材に適用された信頼分類は、AIクライアントとユーザーにソースボディの指示をシステム権限として扱うなと注意させるものです。
