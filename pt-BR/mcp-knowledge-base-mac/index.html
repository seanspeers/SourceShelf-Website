Acesso de conhecimento MCP apenas de leitura

Deixe aplicativos de IA compatíveis pesquisarem um pacote - não todo o seu Mac

MCP é uma conexão padrão entre aplicativos. SourceShelf usa isso para publicar um pacote de conhecimento salvo como uma instantânea local somente de leitura que um cliente de IA compatível pode pesquisar e ler.

MCP sem o jargão

Um aplicativo de IA compatível às vezes precisa de uma maneira de solicitar informações de outro aplicativo. O Model Context Protocol fornece essa conexão.

Com o SourceShelf, você escolhe um pacote salvo e o autoriza para Acesso Local de IA. O cliente de IA pode então pedir ao SourceShelf para encontrar passagens relevantes e ler recursos de texto aprovados desse pacote.

Um limite de pacote que você pode entender

SourceShelf não expõe a Biblioteca ao vivo nem fornece ao cliente uma ferramenta geral de sistema de arquivos. Ele cria uma cópia imutável do pacote selecionado sob um identificador de autorização aleatório.

A captura de tela contém Markdown copiado, imagens locais referenciadas, um catálogo, soma de verificação e uma lista de permissões. Exclui caminhos originais, caminhos de pastas de saída, marcadores de segurança e todas as fontes da Biblioteca fora do pacote.

Pesquise primeiro, leia apenas o que é necessário

Um cliente compatível primeiro pede ao SourceShelf para encontrar passagens relevantes dentro do pacote autorizado. Ele pode então ler uma fonte de texto aprovada em páginas limitadas em vez de carregar todos os documentos de uma vez.

Detalhes avançados do MCP

Veja as ferramentas de leitura exclusiva exatas e o limite de conexão
  • search_pack encontra passagens relevantes conscientes da estrutura dentro do pacote autorizado.
  • read_pack_resource lê uma fonte de texto listada como permitida em páginas limitadas.
  • O assistente não fornece prompts, assinaturas, ferramentas de escrita, caminhos arbitrários, recuperação remota ou ouvinte de rede.
  • O cliente de IA compatível inicia o auxiliar localmente e o SourceShelf recarrega as informações de autorização para cada solicitação.

Sem acesso de escrita e sem servidor de rede

O auxiliar SourceShelf MCP não pode editar fontes, excluir arquivos, recuperar conteúdo remoto, navegar por caminhos arbitrários ou ouvir por conexões de rede. Ele se comunica localmente através de um comando iniciado pelo cliente de IA compatível.

Parar uma partilha ou desativar o MCP invalida a configuração copiada imediatamente.

Modelos locais ou baseados em nuvem continuam sendo sua escolha.

MCP conecta o cliente de IA de desktop ao SourceShelf. O cliente pode usar um modelo executado no Mac ou um modelo baseado em nuvem.

O SourceShelf controla a conexão de conhecimento local, mas não controla a política de privacidade ou o tratamento de dados do cliente de IA de terceiros que você escolher.

Perguntas comuns

O que saber antes de começar

O que significa MCP?

Model Context Protocol é uma maneira padrão de aplicativos compatíveis solicitarem contexto e ferramentas de outro aplicativo. SourceShelf o usa para acesso local, somente leitura a um pacote de conhecimento autorizado.

O MCP dá acesso de IA ao meu Mac inteiro?

Não. SourceShelf expõe apenas a instantânea imutável do pacote salvo que você autoriza.

A IA pode alterar meus documentos?

Não. O SourceShelf não fornece ferramentas de gravação, exclusão ou arquivos arbitrários do MCP.

Um cliente de IA baseado em nuvem pode usar a conexão?

Potencialmente, quando seu aplicativo desktop suportar a conexão local MCP necessária. Os termos de privacidade e tratamento de dados do próprio cliente de terceiros ainda se aplicam.

Como eu revogo o acesso?

Pare a partilha de pacotes individuais ou desative o Acesso Local à IA no SourceShelf. O auxiliar recarrega as informações de autorização para cada solicitação, então o acesso revogado para de funcionar imediatamente.
