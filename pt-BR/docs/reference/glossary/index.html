Glossário

Ativo arquivado
Uma imagem copiada para o armazenamento local gerenciado pelo SourceShelf a partir de uma captura ou conversão suportada. As exportações incluem apenas ativos referenciados pelo Markdown legível selecionado.

linha de base
Os hashes, metadados, datas, formato, IDs de origem e ordenação salvos após a entrega bem-sucedida do pacote são usados pelo Refresh & Compare como o estado "então".

Capturar receita
Uma política de captura do Safari reutilizável para modelos de destino, YAML, modo de conteúdo, comportamento de imagem/link, revisão, regras de domínio e estaleamento.

biblioteca
O navegador pesquisável para fontes convertidas e capturadas. Não é o pacote atual.

Pacote de vida
Um pacote salvo com uma linha de base de exportação bem-sucedida que pode classificar fontes locais como novas, alteradas, ausentes, inalteradas ou removidas.

Acesso local de IA
Obtenção de consentimento da SourceShelf MCP Compartilhamento do fluxo de trabalho para um pacote salvo.

MCP
Protocolo de Contexto de Modelo, um padrão através do qual um host de IA pode descobrir recursos e ferramentas de um servidor. SourceShelf usa apenas stdio local.

OKF
Formato de Conhecimento Aberto. O SourceShelf exporta metadados conceituais canônicos v0.2 com extensões de manifestação SourceShelf.

pacote
Uma seleção ordenada de IDs de fontes da Biblioteca. Um pacote salvo pode ser exportado, comparado ou compartilhado.

Revisão da receita
Uma etapa de fila opcional que permite que você edite o Markdown capturado e os metadados de destino antes de salvar.

Bloco de recuperação
Uma seção limitada, consciente da estrutura de uma fonte gravada em chunks.jsonl Com IDs estáveis, proveniência, hashes, cabeçalhos e contagem estimada de tokens. Não é uma incorporação.

Documento semântico
A representação local versátil da SourceShelf de cabeçalhos, parágrafos, listas, tabelas, código, imagens, legendas, limites de página, citações e conteúdo de backup.

Compartilhar ID
Uma autorização local aleatória identificando uma publicada MCP Captura de tela.

foto
Um imutável, com escopo de pacote MCP Cópia de Markdown legível, ativos referenciados, catálogo, llms.txt, somas de verificação e lista de permissões.

Confiança e Segurança
O relatório pré-voo para legibilidade, embalagem, frescura, somas de verificação, ativos e padrões conservadores de instruções não confiáveis. É de caráter consultivo, não de higienização.

Referência não confiável
A classificação de confiança aplicada ao material capturado e convertido para lembrar os clientes e usuários de IA de não tratar as instruções de corpo de origem como autoridade do sistema.
