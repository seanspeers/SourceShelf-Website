Primeiros passos

  1. Instale o SourceShelf na Mac App Store.
  2. Abra o aplicativo uma vez.
  3. Escolha ou confirme uma pasta de saída.
  4. Ative a extensão do Safari nas Configurações do Safari.
  5. Capture páginas da web ou arraste arquivos/pastas para o aplicativo.
  6. Selecione fontes, revise o Pack Health, e exporte um Pack de Referência de IA quando estiver pronto.

Ajuda da extensão do Safari

A extensão pode salvar páginas inteiras, conteúdo principal, texto selecionado ou áreas visíveis selecionadas. As capturas são encaminhadas através do aplicativo SourceShelf para salvamento local. Quando o Safari pode acessar imagens localizadas no navegador em aplicativos da web autenticados, o SourceShelf pode preservar essas imagens com o Markdown capturado.

Exportação de pacotes de referência para IA

Capturas e documentos selecionados podem ser exportados como ZIPs estruturados para ferramentas de IA, arquivos de longo prazo e reutilização, incluindo pacotes compatíveis com OKF baseados no Google's Open Knowledge Format (OKF) especificação.

  • Cada fonte selecionada se torna sua própria página Markdown.
  • As exportações compatíveis com OKF organizam o conteúdo como documentos de conceito Markdown com metadados para navegação amigável para agentes.
  • Outras exportações de pacotes incluem um índice claro, um manifesto e um arquivo Markdown combinado.
  • Imagens que foram capturadas ou arquivadas localmente podem viajar com o Markdown.

Status do pacote

O Pack Health mostra se o conteúdo selecionado está pronto, tem avisos ou precisa de atenção antes da exportação.

  • Marcadores sem Markdown, links de imagens locais quebrados, imagens arquivadas ausentes e nomes de páginas duplicados.
  • Llama para imagens remotas, mídia salta e documentos vinculados que permanecem como links em vez de arquivos agrupados.

Importação de documentação

Arraste-o para uma pasta de documentação HTML exportada e o SourceShelf se concentra nas páginas reais em vez de em todos os ícones, capturas de tela ou arquivos de suporte. As exportações no estilo Confluence podem se tornar páginas Markdown limpas com imagens relevantes anexadas à página correta.

Formatos compatíveis

  • Capturas do Safari
  • PDFs com texto selecionável
  • PDFs digitalizados via OCR local
  • TXT
  • Markdown
  • HTML
  • Pastas de documentação HTML exportadas
  • Exportações HTML no estilo Confluence
  • RTF
  • PNG
  • JPEG
  • TIFF
  • HEIC/HEIF where supported
  • DOCX
  • PPTX
  • XLSX
  • Pastas contendo arquivos suportados

Problemas comuns

A extensão do Safari não aparece

Ative-o nas Configurações do Safari e reabra o Safari.

As capturas estão na fila

Abra o Open SourceShelf e autorize a pasta de saída.

A qualidade do OCR varia

O OCR é local e de melhor esforço. Use cópias claras/de alta resolução.

Arquivos antigos do Office

Salvar como .docx, .pptx, ou .xlsx Primeiro.

Arquivos ausentes em Recentes

O arquivo Markdown gerado pode ter sido movido ou excluído.

O status do pacote mostra avisos

Revise a falta de Markdown, links de imagens quebrados, imagens arquivadas ausentes, nomes de páginas duplicados, mídia ignorada e documentos vinculados antes da exportação.

As imagens remotas não são incluídas

Imagens remotas podem permanecer como links, a menos que sejam capturadas ou arquivadas localmente primeiro.

A exportação de documentação inclui arquivos adicionais

Use o fluxo de importação de documentação para que o SourceShelf possa se concentrar nas páginas reais e anexar imagens relevantes ao arquivo Markdown correto.

O armazenamento local está aumentando

Use a página Privacidade Local para revisar ativos da web arquivados, uso de armazenamento e limpeza cuidadosa apenas para arquivos verdadeiramente órfãos.

Limitações conhecidas

  • Arquivos antigos do Office .doc, .ppt, .xls não são compatíveis atualmente.
  • OCR é o melhor esforço.
  • O layout complexo do documento pode não ser preservado perfeitamente.
  • Imagens remotas e documentos vinculados podem permanecer vinculados se não foram capturados ou arquivados localmente.
  • O espelhamento da estrutura de pastas e a observação de pastas não estão atualmente incluídos.
