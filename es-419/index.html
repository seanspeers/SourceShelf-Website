SourceShelf

Convierte páginas web, archivos y carpetas en Markdown local y en paquetes de conocimiento para IA compatibles con OKF.

Captura páginas web desde Safari, convierte documentos y carpetas de documentación a Markdown, conserva imágenes útiles y exporta paquetes de referencia para IA estructurados —incluidos paquetes Open Knowledge Format— de forma local en tu Mac.

Qué hace

Un solo lugar para tus fuentes, imágenes y paquetes listos para IA.

Capture, convierta, busque, valide y empaque archivos de origen locales sin enviar su trabajo a un servicio de conversión en la nube.

01

Guardar fuentes como Markdown local

Captura páginas web, archivos y carpetas como Markdown limpio con metadatos de origen preservados.

02

Capturar contenido web desde Safari

Guarda páginas completas, contenido principal, texto seleccionado o áreas visibles de la página directamente desde Safari, incluidas las imágenes locales del navegador que Safari puede acceder durante la captura.

03

Importar carpetas y documentación

Convierte carpetas enteras de PDF, archivos de Office, imágenes, HTML, texto, Markdown y sitios de documentación exportados.

04

Elementos recientes con búsqueda y filtros

Encuentre las fuentes adecuadas rápidamente, incluso cuando su archivo local crezca.

05

Convierte capturas y documentos seleccionados en exportaciones ZIP estructuradas, incluyendo paquetes compatibles con OKF con páginas Markdown, metadatos e índice.

06

OCR escanea PDFs e imágenes localmente en tu Mac.

07

Paquetes de referencia para IA

Comprueba qué está listo antes de exportar.

Pack Health te ayuda a entender qué se incluirá en el paquete, qué necesita atención y qué se mantendrá vinculado antes de crear un paquete de conocimientos reutilizable o una exportación compatible con OKF.

Estado de preparación del paquete

  • Verifique si el contenido seleccionado está listo, tiene advertencias o necesita atención.
  • Identifique problemas con Markdown faltante, enlaces de imágenes locales rotos, imágenes archivadas faltantes y nombres de páginas duplicados temprano.

Contenido claro del paquete

  • Cada fuente seleccionada se convierte en su propia página Markdown para una navegación y reutilización fáciles.
  • Exportar ZIPs de paquetes compatibles con OKF basados en el de Google Open Knowledge Format (OKF) especificación.
  • Las imágenes remotas, los medios omitidos y los documentos enlazados se señalan cuando permanecen como enlaces en lugar de archivos empaquetados.

Las imágenes acompañan al contenido

Capturas de pantalla de la web, diagramas, imágenes incorporadas e imágenes locales del navegador de aplicaciones autenticadas como Confluence pueden viajar con el Markdown capturado cuando Safari puede acceder a ellos.

Archivos a largo plazo más seguros

Las imágenes son propiedad del registro del elemento SourceShelf, por lo que mover o eliminar un archivo Markdown exportado no destruye automáticamente los activos archivados.

información interna

Creado para carpetas de fuentes reales, con límites claramente indicados.

Entradas compatibles

  • Capturas de Safari
  • PDF con texto seleccionable
  • PDF escaneados a través de OCR local
  • TXT
  • Markdown
  • HTML
  • Carpetas de documentación HTML exportadas
  • Exportaciones HTML en estilo Confluence
  • RTF
  • PNG
  • JPEG
  • TIFF
  • HEIC/HEIF where supported
  • DOCX
  • PPTX
  • XLSX
  • Carpas que contienen archivos compatibles

Limitaciones actuales

  • Archivos antiguos de Office .doc, .ppt, .xls no son compatibles actualmente.
  • OCR es el mejor esfuerzo posible.
  • La disposición compleja del documento puede no ser preservada perfectamente.
  • La duplicación de la estructura de carpetas y la supervisión de carpetas no están actualmente incluidas.
