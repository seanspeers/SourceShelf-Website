SourceShelf

Privacy Policy

SourceShelf is designed as a local-first Mac app. It processes captures, conversions, archived assets, pack checks, cleanup, and exports on your Mac and does not use cloud conversion, analytics, telemetry, accounts, or external conversion APIs.

What stays local

  • Safari captures
  • File/folder conversions
  • Documentation site imports
  • Scanned PDF and image OCR using local Apple Vision
  • Context Pack and OKF-compatible bundle generation
  • Pack Health checks for AI Reference Packs
  • Archived web assets and sidecar image folders
  • Local storage usage and orphaned-asset cleanup
  • Recent history
  • Saved selections/collections
  • Safari handoff queue

Where files are stored

Generated Markdown files are saved to the user-selected output folder. Captured images can be saved alongside Markdown in readable sidecar folders such as Page Name.assets. AI Reference Pack ZIPs, OKF-compatible bundle ZIPs, and Context Packs are saved or copied where the user chooses. App history, settings, saved selections, and archived web assets are stored locally in the app/app-group container.

Images are tracked by the SourceShelf item record, so moving or deleting an exported Markdown file does not automatically destroy the archived assets.

Local storage and cleanup

The Local Privacy page explains archived web assets, shows local storage usage, and offers careful cleanup for truly orphaned files only. Cleanup is designed to avoid removing assets still owned by a SourceShelf item record.

What SourceShelf does not do

  • No telemetry
  • No analytics
  • No cloud OCR
  • No cloud conversion
  • No external conversion APIs
  • No account required

After export

Exported Markdown files, sidecar asset folders, Context Packs, AI Reference Pack ZIPs, and OKF-compatible bundle ZIPs are normal files. You control where you save, copy, upload, or share them.

Website privacy

This website uses no analytics, tracking scripts, advertising pixels, cookies, or external fonts/CDNs. GitHub Pages or DNS/hosting providers may process ordinary server logs as part of hosting.

SourceShelf stores only your theme and language preferences locally in your browser. These preferences are not used for tracking and are never sent to SourceShelf.

For privacy questions, email support@sourceshelf.app.
