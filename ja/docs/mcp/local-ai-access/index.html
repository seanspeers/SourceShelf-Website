ローカルAIアクセス（MCP）

ローカルAIアクセスを使用すると、互換性のあるAIアプリケーションは、保存されたSourceShelfパックを繰り返しエクスポートしてアップロードすることなく、検索して読み込むことができます。共有はローカルで、読み取り専用で、パック範囲内で、デフォルトではオフになっています。

SourceShelfはモデルコンテキストプロトコル (MCP）標準の入力/出力を超えます。 Web サーバーまたはネットワークリスナーを開始しません。

クライアントを接続する前に #

  1. 開いている SourceShelf > 設定 > 統合。
  2. 有効にする 地元の MCP 共有する。
  3. 開いている パック そして、保存したパックを選択します。
  4. 未完了の変更を保存します。
  5. 選ぶ もっと見る>ローカルAIアクセス…。
  6. 最新のTrust & Safetyの結果を確認します。警告や読み取り可能なソースエラーがある場合は、明示的に選択します。 問題と共有する 続けるために。

タイトルのないまたは汚れたパックは共有できません。読み取り可能なソースがないパックはブロックされます。

SourceShelfが公開するもの #

各承認により、ランダムな共有IDと、選択したパッケージのみを含む不変のスナップショットが作成されます。

  • 順序付けされたソースリンクを含むパッケージの概要。
  • 生成された llms.txt インデックス；
  • 公開JSONカタログ；
  • 読み取り可能なソースごとに1つのMarkdownリソース。
  • 参照されたアーカイブ画像。
  • チェックサムと内部 URI 許可リスト。

スナップショットはします そうしない ソースファイルのパス、出力フォルダのパス、セキュリティブックマーク、関連のないライブラリアイテム、または書き込みアクセスを含める。

テキストには、保存されたMarkdownボディを変更せずに、信頼できない参照通知を前置することが記載されています。要求されたすべての URI スナップショット許可リストとその SHA-256 提供される前にチェックサム。

リソースとツール #

サーバーは発見可能なものを公開します sourceshelf://pack/... リソースと2つの読み取り専用ツール：

search_pack(query, limit) #

共有パックをローカルで検索し、ランキングされた抜粋とリソースを返します URIs。検索は決定論的で語彙的であり、エンベディングを使用せず、ネットワークリクエストを実行せず、モデルを呼び出しません。

read_pack_resource(uri, cursor, max_characters) #

境界付きページでテキストリソースを読み込みます。カーソルは、小さなモデルのコンテキストウィンドウをオーバーフローさせずに、クライアントが長いソースを継続できるようにします。

このペアは、ローカルモデルにとって特に便利です。モデルは絞り込みして検索でき、最も関連性の高いソースセクションのみを読み取り、SourceShelfを引用できます。 URIs. 互換性のあるホストは、まだモデルがツールを呼び出すことを許可する必要があります。

接続詳細をコピーする #

その ローカルAIアクセス シートは提供します：

  • コピー MCP 設定 — 共通のJSON mcpServers 使用されるフォーマット LM Studio そしていくつかのクライアントたち。
  • コピーコマンド — ヘルパー実行ファイルプラス --share 承認の議論；
  • 思い出す — 必要に応じて、明示的なレビューの後、スナップショットを再構築します。
  • 共有を停止する — すぐに承認を取り消します。

コピーされた共有IDをローカルアクセストークンのように扱う必要があります。これはインターネット経由で送信されたパスワードではなく、IDとヘルパーパスを持つユーザーとして実行されているどのプロセスでもそのスナップショットを要求できます。

スナップショットの更新と取り消し #

SourceShelf は、関連するパッケージ、ライブラリ、およびトラストポリシーの変更後、株式を再評価します。

  • 新しいTrust & Safetyの結果が準備ができたら、SourceShelfはスナップショットを自動的に置き換えることができます。
  • 新しい警告やエラーが表示された場合、以前の有効なスナップショットは引き続き使用可能で、共有は レビューが必要。
  • 選択する 思い出す そして、それらの変更をパブリッシュする前に確認してください。
  • 保存したパックを削除すると、その共有権が取り消されます。
  • 共有を停止する、 すべて取り消す、またはローカルを無効にする MCP 共有すると、コピーした構成はすぐに無効になります。

ヘルパーは、各リクエストに対してレジストリとスナップショットメタデータを再読み込みするため、実行中のクライアントは取り消された共有物を読み続けることができません。

SourceShelf の移動または更新 #

コピーされた構成は、SourceShelfアプリ内のヘルパーを指します。SourceShelfを移動、再インストール、または更新する場合は、から新しい構成をコピーします。 ローカルAIアクセス... したがって、AIクライアントは現在のヘルパー位置を使用します。

クライアントガイドを選択する #

  • LM Studio
  • Ollama
  • Codex
  • Claude Code
  • OpenCode

見てみる MCP トラブルシューティング ヘルパーが終了した場合、ツールが欠落している場合、または共有ファイルが最新でない場合。

プロトコルノート #

SourceShelfのヘルパーは使用します MCP stdioを超え、バンドルされたSwift SDKによって実装されたプロトコルバージョンをサポートします。サーバーはリソースと2つの読み取り専用ツールのみをパブリッシュします。プロンプト、書き込みツール、サブスクリプション、リスト変更通知はパブリッシュしません。

さらなる読書： MCP 資源、 MCP ツール。
