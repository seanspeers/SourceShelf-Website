SourceShelf

ウェブページ、ファイル、フォルダをローカルMarkdownやOKF互換のAI向けナレッジパックに変換します。

Safariからウェブページを取り込み、文書やドキュメントフォルダをMarkdownに変換し、必要な画像を保持して、Open Knowledge Formatを含む構造化されたAIリファレンスパックを書き出します。すべてMac上でローカルに処理されます。

Mac App Storeからダウンロード プライバシーの詳細を見る

機能

ソース資料、画像、AI向けパックを一か所に。

クラウド変換サービスに作業を送信することなく、ローカルソースファイルをキャプチャ、変換、検索、検証、およびパッケージ化します。

01

ソースをローカルMarkdownとして保存

ウェブページ、ファイル、フォルダをソースメタデータを保持したクリーンなMarkdownとしてキャプチャします。

02

SafariからWebコンテンツをキャプチャ

Safari から、ブラウザ内の画像を含む、ページ全体、メインコンテンツ、選択したテキスト、または表示されるページ領域を直接保存できます。この機能は、キャプチャ中に Safari がアクセスできるブラウザ内の画像も対象となります。

03

フォルダとドキュメントをインポート

PDF、オフィスファイル、画像、HTML、テキスト、Markdown、およびエクスポートされたドキュメントサイトのフォルダ全体を変換します。

04

最近使った項目を検索・絞り込み

ローカルアーカイブが成長しても、すぐに適切なソースを見つけてください。

05

AI向けナレッジパックを書き出す

選択したキャプチャとドキュメントを、Markdownページ、メタデータ、インデックスを含むOKF互換のバンドルを含む構造化されたZIPエクスポートに変換します。

06

スキャンPDFのOCR

OCRは、Mac のローカルで PDF や画像をスキャンします。

07

画像を含むMarkdownを生成

ソースメタデータを保持した読みやすいマークダウン、および次のとおりの明確なサイドカーフォルダに保存された画像。 Page Name.assets.

08

プライバシーを重視した設計

キャプチャ、資産、パックチェック、クリーニング、エクスポートはすべて、クラウド処理やテレメトリなしでMac上でローカルで行われます。

09

ショートカット／自動化

Appleショートカットでマークダウン変換を自動化します。

AIリファレンスパック

書き出す前に準備状況を確認できます。

パッケージヘルスは、再利用可能な知識パッケージやOKF互換のエクスポートを作成する前に、どのようなものがバンドルされるか、どのようなものが注意が必要なのか、どのようなものがリンクされているかを理解するのに役立ちます。

パックの準備状況

  • 選択したコンテンツが準備ができているか、警告があるか、または注意が必要なかどうかを確認します。
  • マークダウンが欠落している、ローカル画像リンクが壊れている、アーカイブされた画像が欠落している、ページ名が重複していることを早期に発見します。

バンドル内容を明確に確認

  • 選択された各ソースは、簡単に見出しと再利用のために独自のMarkdownページになります。
  • GoogleのベースでOKF互換のバンドルZIPをエクスポートします Open Knowledge Format (OKF) 仕様。
  • リモートイメージ、スキップされたメディア、およびリンクされたドキュメントは、バンドルされたファイルではなくリンクのままの場合に強調表示されます。

画像もコンテンツと一緒に保存

Confluenceなどの認証済みアプリからのウェブスクリーンショット、図解、埋め込み画像、ブラウザローカル画像は、SafariがそれらにアクセスできるときにキャプチャされたMarkdownと一緒に移動できます。

長期保存をより安全に

画像はSourceShelfアイテムレコードに属しているため、エクスポートされたMarkdownファイルを移動または削除しても、アーカイブされた資産は自動的に破棄されません。

詳細

実際のソースフォルダに対応し、現在の制限も明確に示します。

対応する入力

  • Safariのキャプチャ
  • 選択可能なテキストを含むPDF
  • ローカルOCRを介してスキャンされたPDF
  • TXT
  • Markdown
  • HTML
  • エクスポートされたHTMLドキュメントフォルダ
  • コンフルエンセスタイルのHTMLエクスポート
  • RTF
  • PNG
  • JPEG
  • TIFF
  • HEIC/HEIF where supported
  • DOCX
  • PPTX
  • XLSX
  • サポート対象のファイルを含むフォルダ

現在の制限

  • 旧形式のOfficeファイル .doc, .ppt, .xls は現在サポートされていません。
  • OCRは最善の努力です。
  • 複雑なドキュメントのレイアウトは完全に保持されない場合があります。
  • フォルダ構造のミラーリングとフォルダ監視は現在含まれていません。
