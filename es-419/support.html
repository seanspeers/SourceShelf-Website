Primeros pasos

  1. Instala SourceShelf desde la App Store de Mac.
  2. Abre la aplicación una vez.
  3. Elija o confirme una carpeta de salida.
  4. Habilita la extensión de Safari en Configuración de Safari.
  5. Captura páginas web o arrastra archivos/ carpetas a la aplicación.
  6. Seleccione las fuentes, revise la salud del paquete y luego exporte un paquete de referencia de IA cuando esté listo.

Ayuda de la extensión de Safari

La extensión puede guardar páginas enteras, el contenido principal, el texto seleccionado o las áreas visibles seleccionadas. Las capturas se dirigen a través de la aplicación SourceShelf para su guardado local. Cuando Safari puede acceder a imágenes locales del navegador en aplicaciones web autenticadas, SourceShelf puede preservar esas imágenes con el Markdown capturado.

Exportación de paquetes de referencia para IA

Las capturas y documentos seleccionados se pueden exportar como ZIP estructurados para herramientas de IA, archivos a largo plazo y reutilización, incluidos paquetes compatibles con OKF basados en el de Google. Open Knowledge Format (OKF) especificación.

  • Cada fuente seleccionada se convierte en su propia página Markdown.
  • Las exportaciones compatibles con OKF organizan el contenido como documentos conceptuales Markdown con metadatos para una navegación amigable con los agentes.
  • Otras exportaciones del paquete incluyen un índice transparente, un inventario y un archivo Markdown combinado.
  • Las imágenes que se capturaron o archivaron localmente pueden viajar con el Markdown.

Estado del paquete

Pack Health muestra si el contenido seleccionado está listo, tiene advertencias o necesita atención antes de la exportación.

  • Banderas que faltan Markdown, enlaces de imágenes locales rotos, imágenes archivadas faltantes y nombres de páginas duplicados.
  • Llama a imágenes remotas, medios saltados y documentos enlazados que permanecen como enlaces en lugar de archivos empaquetados.

Importación de documentación

Coloca una carpeta de documentación HTML exportada y SourceShelf se centra en las páginas reales en lugar de cada icono, captura de pantalla o archivo de soporte. Las exportaciones al estilo Confluence pueden convertirse en páginas Markdown limpias con imágenes relevantes adjuntas a la página correcta.

Formatos compatibles

  • Capturas de Safari
  • PDF con texto seleccionable
  • PDF escaneados a través de OCR local
  • TXT
  • Markdown
  • HTML
  • Carpetas de documentación HTML exportadas
  • Exportaciones HTML en estilo Confluence
  • RTF
  • PNG
  • JPEG
  • TIFF
  • HEIC/HEIF where supported
  • DOCX
  • PPTX
  • XLSX
  • Carpas que contienen archivos compatibles

Problemas comunes

La extensión de Safari no aparece

Actívalo en la Configuración de Safari y vuelva a abrir Safari.

Las capturas están en espera

Abra Open SourceShelf y autorice la carpeta de salida.

La calidad del OCR varía

El OCR es local y de la mejor manera posible. Utilice escaneos claros/de alta resolución.

Archivos antiguos de Office

Guardar como .docx, .pptx, o .xlsx primero.

Faltan archivos en Recientes

El archivo Markdown generado puede haber sido movido o eliminado.

El estado del paquete muestra advertencias

Revisa la falta de Markdown, los enlaces de imágenes rotos, las imágenes archivadas faltantes, los nombres de páginas duplicados, los medios omitidos y los documentos enlazados antes de la exportación.

Las imágenes remotas no se incluyen

Las imágenes remotas pueden permanecer como enlaces a menos que se hayan capturado o archivado localmente primero.

La exportación de documentación incluye archivos adicionales

Utilice el flujo de importación de documentación para que SourceShelf pueda centrarse en las páginas reales y adjuntar imágenes relevantes al archivo Markdown correcto.

El almacenamiento local está creciendo

Utilice la página de Privacidad Local para revisar los activos web archivados, el uso del almacenamiento y la limpieza cuidadosa solo para archivos verdaderamente huérfanos.

Limitaciones conocidas

  • Archivos antiguos de Office .doc, .ppt, .xls no son compatibles actualmente.
  • OCR es el mejor esfuerzo posible.
  • La disposición compleja del documento puede no ser preservada perfectamente.
  • Las imágenes remotas y los documentos enlazados pueden permanecer enlazados si no se capturaron o archivaron localmente.
  • La duplicación de la estructura de carpetas y la supervisión de carpetas no están actualmente incluidas.
