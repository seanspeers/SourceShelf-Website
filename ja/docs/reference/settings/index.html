言語 #

SourceShelfは、英語、フランス語、ラテンアメリカのスペイン語、ブラジルポルトガル語、日本語に対応しています。システム設定 > 一般 > 言語と地域 > アプリケーションでSourceShelfに指定した言語を使用します。指定がない場合は、macOSの優先言語の順序に従います。Safari拡張機能はSafariの表示言語に従います。

表示言語を変更しても、元の文書、独自に付けたレシピ名やパック名、書き出した本文、MCP識別子、ファイル名、マニフェストのフィールドは翻訳されません。

将軍 #

新しい変換およびキャプチャされたMarkdownに使用される出力フォルダを選択します。SourceShelfは、承認されたブックマークをローカルに保存するため、そのフォルダに戻すことができます。変更すると、将来の出力に影響します。既存のファイルは移動されません。

ストレージを確認する... インベントリがMarkdownを生成し、予測された出力資産、管理されたライブラリコピー、セマンティックキャッシュ、ローカル MCP スナップショット、およびドラフト/ステージングのキャプチャ。安全なクリーンアップは、孤立したまたは再生成可能な内部データのみを削除します。生成ソースクリーンアップは、出力ファイルをゴミ箱に移動する別の選択と確認ワークフローです。スター付きおよび保存済みパッケージソースはデフォルトで保護され、元のインポートされたドキュメントは決して削除対象ではありません。 見てみる SourceShelfストレージを管理する 完全なワークフローのために。

捕獲 #

キャプチャ設定には、以下が含まれます。

  • Safari拡張機能のステータスと、Safariの拡張機能設定へのショートカット。
  • ドメインと日付による組織化；
  • アーカイブされたウェブイメージの動作；
  • グローバルウェブキャプチャの陳腐化時代；
  • レシピの作成、複製、削除、オーダー、テンプレート、YAML、動作、およびドメインルールをキャプチャします。
  • Safariのクイックキャプチャキーボードアクションとその推奨レシピ。

レシピの変更はローカルに保存され、SourceShelf Safari拡張機能に公開されます。

エクスポート #

パッケージのエクスポート選択者で最初に選択した形式を選択します。設定と選択者は同じプリファレンスを共有します。異なる選択を確認すると更新され、キャンセルすると更新されません。

AI リファレンス パック ZIP にリトラバリング チャンクを含める モデルニュートラルを追加する chunks.jsonl。デフォルトではオンになり、エンベディングは追加されません。

統合 #

ローカルを有効にする MCP 共有する デフォルトではオフになっています。有効にすると、個々の保存済みパックを以下から承認できます。 パック>その他>ローカルAIアクセス...。

このタブには、アクティブシェア数が表示され、 開封したパック そして すべて取り消す。共有を無効にするか、すべてを解除すると、スナップショットが削除され、コピーされたクライアント構成がすぐに無効になります。

見てみる ローカルAIアクセス。

プライバシー #

このタブでは、ローカルストレージ、エクスポート、リトライチャンク、Living Pack の比較、およびアドバイス付きの Trust & Safety 動作をまとめています。 プライバシー詳細を開く アプリ内の完全なプライバシー説明を開きます。
