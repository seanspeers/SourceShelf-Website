Acceso de conocimiento MCP solo de lectura

Deja que las aplicaciones de IA compatibles busquen un paquete, no todo tu Mac.

MCP es una conexión estándar entre aplicaciones. SourceShelf la utiliza para publicar un paquete de conocimiento guardado como una instantánea local de solo lectura que un cliente de IA compatible puede buscar y leer.

MCP sin jerga

A veces, una aplicación de IA compatible necesita una forma de solicitar información de otra aplicación. Model Context Protocol proporciona esa conexión.

Con SourceShelf, elige un paquete guardado y lo autorizas para el acceso local a la IA. El cliente de IA puede entonces pedirle a SourceShelf que encuentre pasajes relevantes y lea recursos de texto aprobados de ese paquete.

Un límite de paquete que puedes entender

SourceShelf no expone la Biblioteca en vivo ni le da al cliente una herramienta general de sistema de archivos. Crea una copia inmutable del paquete seleccionado bajo un identificador de autorización aleatorio.

La instantánea contiene Markdown copiado, imágenes locales referenciadas, un catálogo, comprobaciones de integridad y una lista de permisos. Excluye los rutas originales, las rutas de las carpetas de salida, las marcadores de seguridad y todas las fuentes de la Biblioteca fuera del paquete.

Busca primero, lee solo lo que sea necesario

Un cliente compatible primero pide a SourceShelf que encuentre pasajes relevantes dentro del paquete autorizado. Luego puede leer una fuente de texto aprobada en páginas limitadas en lugar de cargar todos los documentos de una vez.

Detalles avanzados de MCP

Ver las herramientas de lectura única exactas y el límite de conexión
  • search_pack encuentra pasajes relevantes que son conscientes de la estructura dentro del paquete autorizado.
  • read_pack_resource lee una fuente de texto permitida en páginas limitadas.
  • El asistente no proporciona prompts, suscripciones, herramientas de escritura, rutas arbitrarias, obtención remota ni escucha de red.
  • El cliente de IA compatible inicia el asistente localmente y SourceShelf recarga la información de autorización para cada solicitud.

Sin acceso de escritura y sin servidor de red

El asistente SourceShelf MCP no puede editar fuentes, eliminar archivos, obtener contenido remoto, navegar por rutas arbitrarias ni escuchar conexiones de red. Se comunica localmente a través de un comando lanzado por el cliente de IA compatible.

Detener una acción o deshabilitar MCP invalida la configuración copiada inmediatamente.

Los modelos locales o respaldados por la nube siguen siendo tu elección

MCP conecta al cliente de IA de escritorio con SourceShelf. El cliente puede usar un modelo que se ejecuta en el Mac o un modelo respaldado por la nube.

SourceShelf controla la conexión de conocimiento local, pero no controla la política de privacidad ni el manejo de datos del cliente de IA de terceros que elija.

Preguntas comunes

Qué saber antes de comenzar

¿Qué significa MCP?

Model Context Protocol es una forma estándar para que las aplicaciones compatibles soliciten contexto y herramientas a otra aplicación. SourceShelf lo utiliza para acceder localmente, solo de lectura, a un paquete de conocimientos autorizado.

¿MCP da acceso a IA a todo mi Mac?

No. SourceShelf solo expone la instantánea inmutable del paquete guardado que autoriza.

¿Puede la IA cambiar mis documentos?

No. SourceShelf no proporciona herramientas de escritura, eliminación o archivos arbitrarios de MCP.

¿Un cliente de IA respaldado por la nube puede usar la conexión?

Potencialmente, cuando su aplicación de escritorio admita la conexión local MCP requerida. Los términos de privacidad y manejo de datos propios del cliente de terceros siguen aplicándose.

¿Cómo revoco el acceso?

Para evitar que el acceso local de IA funcione de inmediato, desactive el acceso de IA local en SourceShelf o detenga la participación del paquete individual. La ayuda recarga la información de autorización para cada solicitud, por lo que el acceso revocado deja de funcionar inmediatamente.
