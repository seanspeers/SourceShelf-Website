Casos de uso de SourceShelf

Formas de usar SourceShelf

Comience con el flujo de trabajo que se adapte al conocimiento que desea capturar, organizar o conectar.

Base de conocimientos privada de IA para Mac

Convierte tu Mac en una base de conocimientos privada de IA

Capture, convierta, organice y conecte el conocimiento seleccionado con procesamiento local y acceso de IA de lectura única.

Conversión local de PDF

Convierte PDFs a útiles Markdown, todo en tu Mac.

Extraiga el texto o use el OCR local de Apple, luego inspeccione, edite, archive o agregue el Markdown a un paquete enfocado.

Captura web de Safari

Guarda la parte de una página web que realmente necesitas

Capture páginas completas, artículos, selecciones, áreas o destacados ordenados de Safari y guárdelos como Markdown locales.

Contexto enfocado para IA

Dale a la IA un paquete de referencia enfocado, no una carpeta sin estructura.

Seleccione y organice las fuentes que le importan, luego exporte el contexto portátil o comparta el paquete guardado de forma no editable.

Archivo de investigación local

Cree un archivo de investigación que aún pueda usar años después

Captura la investigación web, convierte documentos, preserva la procedencia y guarda los resultados como paquetes Markdown portátiles y guardados.

Acceso de conocimiento MCP solo de lectura

Deja que las aplicaciones de IA compatibles busquen un paquete, no todo tu Mac.

Autorice un paquete guardado como una instantánea local de solo lectura que un cliente de IA compatible puede buscar y leer.

Crea la base de conocimiento que le faltaba a tu IA.

Elige las fuentes adecuadas, conserva el control de los originales y reutiliza contexto específico con asistentes compatibles.
