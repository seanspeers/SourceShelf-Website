Bien démarrer

  1. Installez SourceShelf depuis l'App Store Mac..
  2. Ouvrez l'application une fois.
  3. Choisissez ou confirmez un dossier de sortie.
  4. Activez l'extension Safari dans les paramètres de Safari.
  5. Capturez des pages Web ou faites glisser des fichiers/dossiers dans l'application.
  6. Sélectionnez les sources, examinez la santé du pack, puis exportez un pack de référence IA lorsque vous êtes prêt.

Aide sur l’extension Safari

L'extension peut enregistrer des pages entières, le contenu principal, le texte sélectionné ou les zones visibles sélectionnées. Les captures sont acheminées via l'application SourceShelf pour l'enregistrement local. Lorsque Safari peut accéder aux images locales du navigateur dans les applications Web authentifiées, SourceShelf peut conserver ces images avec le Markdown capturé.

Exportation d’un pack de référence IA

Les captures et documents sélectionnés peuvent être exportés sous forme de ZIP structurés pour les outils d'IA, les archives à long terme et la réutilisation, y compris les paquets compatibles OKF basés sur le système de Google. Open Knowledge Format (OKF) spécification.

  • Chaque source sélectionnée devient sa propre page Markdown.
  • Les exportations compatibles avec OKF organisent le contenu sous forme de documents conceptuels Markdown avec des métadonnées pour une navigation conviviale pour les agents.
  • Les autres exportations de paquets comprennent un indice clair, un manifeste et un fichier Markdown combiné.
  • Les images capturées ou archivées localement peuvent voyager avec le Markdown.

État du pack

Pack Health indique si le contenu sélectionné est prêt, s'il contient des avertissements ou s'il nécessite une attention avant l'exportation.

  • Signaux manquants de Markdown, liens d'images locales cassés, images archivées manquantes et noms de pages doublons.
  • Appelle les images distantes, les médias sautés et les documents liés qui restent des liens au lieu de fichiers groupés.

Importation de documentation

Déposez-la dans un dossier de documentation HTML exporté et SourceShelf se concentre sur les pages actuelles au lieu de chaque icône, capture d'écran ou fichier de support. Les exportations au style Confluence peuvent devenir des pages Markdown propres avec des images pertinentes attachées à la bonne page.

Formats pris en charge

  • Captures Safari
  • PDF avec texte sélectionnable
  • PDFs scannés via OCR local
  • TXT
  • Markdown
  • HTML
  • Dossiers de documentation HTML exportés
  • Exportations HTML au style Confluence
  • RTF
  • PNG
  • JPEG
  • TIFF
  • HEIC/HEIF where supported
  • DOCX
  • PPTX
  • XLSX
  • Dossiers contenant des fichiers pris en charge

Problèmes courants

L’extension Safari n’apparaît pas

Activez-le dans les paramètres de Safari et rouvrez Safari.

Les captures sont en attente

Ouvrez Open SourceShelf et autorisez le dossier de sortie.

La qualité de l’OCR varie

L'OCR est local et fait de son mieux. Utilisez des scans nets/à haute résolution.

Anciens fichiers Office

Enregistrer sous .docx, .pptx, ou .xlsx Premier.

Fichiers absents des éléments récents

Le fichier Markdown généré a pu être déplacé ou supprimé.

L’état du pack affiche des avertissements

Vérifiez la présence de Markdown manquant, de liens d'images brisés, d'images archivées manquantes, de noms de pages doublons, de médias omis et de documents liés avant l'exportation.

Les images distantes ne sont pas incluses

Les images distantes peuvent rester des liens à moins qu'elles n'aient d'abord été capturées ou archivées localement.

L’exportation de documentation contient des fichiers supplémentaires

Utilisez le flux d'importation de documentation afin que SourceShelf puisse se concentrer sur les pages actuelles et joindre des images pertinentes au bon fichier Markdown.

Le stockage local augmente

Utilisez la page de confidentialité locale pour examiner les actifs web archivés, l'utilisation du stockage et le nettoyage minutieux uniquement pour les fichiers véritablement orphelins.

Limites connues

  • Anciens fichiers Office .doc, .ppt, .xls ne sont pas pris en charge pour le moment.
  • OCR est un effort maximal.
  • La mise en page complexe du document peut ne pas être préservée parfaitement.
  • Les images distantes et les documents liés peuvent rester des liens s'ils n'ont pas été capturés ou archivés localement.
  • Le miroir de la structure des dossiers et la surveillance des dossiers ne sont pas actuellement incluses.
