Text PDFs and scanned PDFs

SourceShelf handles PDFs that already contain selectable text and image-only PDFs that require OCR. When no usable text is available, it uses Apple's local document-recognition technology on your Mac.

The document does not need to be sent to an online converter or external OCR service.

Useful structure, not just a text dump

SourceShelf builds a semantic representation of the document before rendering Markdown. Where the source allows it, the result retains useful elements such as headings, paragraphs, lists, tables, code, quotations, captions, images, and page boundaries.

Complex layouts and imperfect scans can still require correction, but the result is designed to be readable, inspectable, and portable.

Your Markdown remains yours

Generated Markdown is written to the output folder you choose. Open it in your preferred Markdown editor, reveal it in Finder, or use it with other tools.

SourceShelf detects external edits and regenerates its local semantic cache without overwriting the changes you made.

Common questions

What to know before you begin

Does PDF conversion require an internet connection?

No. SourceShelf performs PDF extraction and OCR locally.

Can it convert scanned PDFs?

Yes. SourceShelf can use local Apple OCR when a PDF has no selectable text.

Will every complex layout be reproduced perfectly?

No. OCR and document reconstruction can require correction, particularly with low-quality scans or complex multi-column layouts. SourceShelf preserves useful structure where extraction allows it.

Can I edit the Markdown afterward?

Yes. The result is a normal Markdown file that opens in your configured editor.
