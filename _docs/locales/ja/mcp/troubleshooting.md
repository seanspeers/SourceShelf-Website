# MCPのトラブルシューティング

SourceShelfから外側に向かって作業します。スナップショット、ヘルパーパス、クライアント接続、次にモデル動作です。

## 1. SourceShelf の状態を確認する

保存したパックの **ローカルAIアクセス** シートと検証する：

- グローバル共有が有効になっています。
- パッケージは保存されており、未保存の変更はありません。
- 公開されたスナップショットが表示されます。
- ステータスは **現在の**、またはあなたは意図的に保持した **レビューが必要** スナップショット；
- スナップショットには少なくとも1つの読み取り可能なソースが含まれています。

選択する **思い出す** 現在の変更をレビューして公開したい場合は。 使う **コピー MCP 設定** SourceShelfのインストールパスの変更があった後、再度実行します。

## 2. コピーしたコマンドを直接テストします。

ペースト **コピーコマンド** ターミナルに。stdio MCP ヘルパーは通常、プロトコル入力に静かに待ちます。これはインタラクティブなシェルアプリケーションではありません。すぐに終了し、診断情報を印刷する場合は、メッセージに共有の欠落、レジストリの無効化、無効なスナップショット、またはチェックサムエラーがないか確認します。待ち中の直接テストを停止するには、Control-Cを押します。

診断は標準エラーに属します。JSON-RPCプロトコルメッセージは標準出力に属します。これらのストリームを統合または書き換えるクライアントは、接続を破損する可能性があります。

## 3. 一般的なエラー

### プロセスはコード1で終了し、接続が閉じました。

可能性のある原因：

- 構成された App が移動、更新、または置き換えられました。
- コピーされたシェアが取り消されました。
- グローバルな MCP 共有は無効になっています。
- スナップショットまたはレジストリを読み込めません。

Open SourceShelfを開き、パック共有を確認し、新しい構成をコピーします。

### 方法が見つかりません。 `tools/list`

クライアントは古いリソースのみのヘルパーに到達しました。現在のSourceShelfバージョンをインストールしてから、コマンドをコピーしてクライアント統合を再起動します。現在のSourceShelfは広告を出しています `search_pack` そして `read_pack_resource`。

### リソースが見つかりません

その URI 別のパック、別の共有、古いスナップショットから、またはスナップショット許可リストに含まれていないかです。 もう一度検索して、読み込んでください。 URI 現在の検索結果によって返されます。

### チェックサムエラー

SourceShelfは、公開されたチェックサムと一致しなくなったスナップショットファイルを提供することを拒否します。 SourceShelfから共有を更新してください。 内部のファイルを編集しないでください `MCP Shares/<share-id>/` 手動で。

### クライアントはリソースを表示しますが、モデルはツールを呼び出すことはありません。

その MCP 接続は機能していますが、モデルまたはホストポリシーがツールコールを発行していません。次のように試してください。

> 最初の電話 `search_pack` 問い合わせ付き `...`。それから電話してください `read_pack_resource` トップの結果に表示されます。両方の通話が完了するまで応答しないでください。

それでもプレーンテキストになる場合は、関数呼び出しをサポートしていることが知られているモデルをテストします。

### 正確なフレーズを検索できませんでした。

句読点が多いテキストではなく、意味のあるコンテンツ用語を使用してください。検索は意味的エンベディング検索ではなく、ローカル語彙リプリケーションです。言い換えや短いフレーズを試してみてください。

### 長いソースが切断されます。

コール `read_pack_resource` 戻されたカーソルで再び。小さい `max_characters` 値は限られた文脈モデルに役立ちます。

## 4. 新しい承認を作成する

クライアントの状態が不明確のままの場合は：

1. AIクライアントからサーバーエントリを削除します。
2. SourceShelf で、 **共有を停止する**。
3. パッケージを保存して再度確認してください。
4. 新しいローカルAIアクセス承認を作成します。
5. 新しくコピーした構成をクライアントに追加します。

新しい承認には新しいシェアIDが割り当てられます。古い構成は無効のままです。
