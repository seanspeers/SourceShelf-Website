SourceShelf

Política de privacidad

SourceShelf está diseñado como una aplicación Mac que prioriza la localización. Procesa capturas, conversiones, activos archivados, comprobaciones de paquetes, limpieza y exportaciones en tu Mac y no utiliza conversión en la nube, análisis, telemetría, cuentas ni API de conversión externas.

Lo que permanece local

  • Capturas de Safari
  • Conversiones de archivos/ carpetas
  • Importaciones de sitios de documentación
  • OCR de PDF y imágenes escaneadas usando Apple Vision local
  • Generación de paquetes Context Pack y OKF-compatible
  • Paquete de controles de salud para paquetes de referencia de IA
  • Recursos web archivados y carpetas de imágenes de sidecar
  • Uso del almacenamiento local y limpieza de activos huérfanos
  • Historia reciente
  • Selecciones/colecciones guardadas
  • Cola de transferencia de Safari

Dónde se guardan los archivos

Los archivos Markdown generados se guardan en la carpeta de salida seleccionada por el usuario. Las imágenes capturadas se pueden guardar junto con el Markdown en carpetas secundarias legibles como Page Name.assets. Reference Pack ZIPs, ZIPs de paquetes compatibles con OKF y Context Packs se guardan o copian donde el usuario elija. El historial de la aplicación, la configuración, las selecciones guardadas y los recursos web archivados se almacenan localmente en el contenedor de la aplicación/grupo de aplicaciones.

Las imágenes se rastrean por el registro del elemento SourceShelf, por lo que mover o eliminar un archivo Markdown exportado no destruye automáticamente los activos archivados.

Almacenamiento local y limpieza

La página de Privacidad Local explica los recursos web archivados, muestra el uso del almacenamiento local y ofrece una limpieza cuidadosa solo para archivos verdaderamente huérfanos. La limpieza está diseñada para evitar eliminar recursos que aún pertenecen a un registro de elemento SourceShelf.

Lo que SourceShelf no hace

  • Sin telemetría
  • Sin análisis
  • No OCR de nube
  • Sin conversión de nube
  • Sin API de conversión externa
  • No se requiere cuenta

Después de exportar

Los archivos Markdown exportados, las carpetas de activos sidecar, los Context Packs, los ZIPs de los Packs de Referencia de IA y los ZIPs de los paquetes compatibles con OKF son archivos normales. Tú controlas dónde guardarlos, copiarlos, cargarlos o compartirlos.

Privacidad del sitio web

Este sitio web no utiliza análisis, scripts de seguimiento, píxeles publicitarios, cookies ni fuentes/CDNs externas. GitHub Pages o los proveedores de DNS/hosting pueden procesar los registros normales del servidor como parte del alojamiento.

SourceShelf solo almacena tus preferencias de tema e idioma localmente en tu navegador. Estas preferencias no se usan para rastrearte y nunca se envían a SourceShelf.

Para preguntas sobre privacidad, envíe un correo electrónico support@sourceshelf.app.
