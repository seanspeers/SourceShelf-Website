Conversion locale de PDF

Convertissez les PDF en Markdown utiles - entièrement sur votre Mac.

Envoyez un texte PDF ou un document numérisé. SourceShelf extrait du contenu lisible, utilise l'OCR local d'Apple lorsque nécessaire et crée un fichier Markdown que vous pouvez inspecter, modifier, archiver ou ajouter à un pack de connaissances IA.

Contenu de la vidéo

Déposez un PDF texte ou un PDF numérisé sur l'écran de conversion SourceShelf.

SourceShelf extrait du texte sélectionnable ou utilise la reconnaissance locale de documents d'Apple lorsque le texte utilisable n'est pas disponible.

Examinez le résultat rendu et la source Markdown, puis corrigez les mises en page complexes ou l'OCR de faible qualité lorsque nécessaire.

Ouvrez le fichier Markdown normal dans un autre éditeur ou ajoutez-le à un pack de connaissances enregistré.

Texte des PDF et des PDF numérisés.

SourceShelf gère les PDF qui contiennent déjà du texte sélectionnable et les PDF contenant uniquement des images qui nécessitent l'OCR. Lorsque aucun texte utilisable n'est disponible, il utilise la technologie de reconnaissance de documents locale d'Apple sur votre Mac.

Le document n'a pas besoin d'être envoyé à un convertisseur en ligne ou à un service OCR externe.

Structure utile, pas seulement un tas de texte.

SourceShelf construit une représentation sémantique du document avant de rendre Markdown. Là où la source le permet, le résultat conserve des éléments utiles tels que les titres, les paragraphes, les listes, les tableaux, le code, les citations, les légendes, les images et les limites de page.

Les mises en page complexes et les scans imparfaits peuvent encore nécessiter une correction, mais le résultat est conçu pour être lisible, inspectable et portable.

Votre Markdown reste le vôtre.

Le Markdown généré est écrit dans le dossier de sortie que vous choisissez. Ouvrez-le dans votre éditeur Markdown préféré, révéléz-le dans Finder ou utilisez-le avec d'autres outils.

SourceShelf détecte les modifications externes et régénère sa cache sémantique locale sans effacer les modifications que vous avez apportées.

Questions fréquentes

Ce que vous devez savoir avant de commencer

La conversion en PDF nécessite-t-elle une connexion Internet ?

Non. SourceShelf effectue l'extraction PDF et l'OCR localement.

Peut-il convertir les PDF scannés ?

Oui. SourceShelf peut utiliser l'OCR local d'Apple lorsque un PDF n'a pas de texte sélectionnable.

Chaque disposition complexe sera-t-elle reproduite parfaitement ?

Non. L'OCR et la reconstruction de documents peuvent nécessiter une correction, en particulier avec des scans de faible qualité ou des mises en page complexes à plusieurs colonnes. SourceShelf préserve la structure utile lorsque l'extraction le permet.

Puis-je modifier le Markdown par la suite ?

Oui. Le résultat est un fichier Markdown normal qui s'ouvre dans votre éditeur configuré.
