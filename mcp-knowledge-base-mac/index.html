MCP without the jargon

A compatible AI application sometimes needs a way to request information from another application. Model Context Protocol provides that connection.

With SourceShelf, you choose a saved pack and authorize it for Local AI Access. The AI client can then ask SourceShelf to find relevant passages and read approved text resources from that pack.

A pack boundary you can understand

SourceShelf does not expose the live Library or give the client a general filesystem tool. It creates an immutable copy of the selected pack under a random authorization identifier.

The snapshot contains copied Markdown, referenced local images, a catalog, checksums, and an allowlist. It excludes original paths, output-folder paths, security bookmarks, and every Library source outside the pack.

Search first, read only what is needed

A compatible client first asks SourceShelf to find relevant passages inside the authorized pack. It can then read an approved text source in bounded pages rather than loading every document at once.

Advanced MCP details

See the exact read-only tools and connection boundary
  • search_pack finds relevant structure-aware passages inside the authorized pack.
  • read_pack_resource reads an allowlisted text source in bounded pages.
  • The helper provides no prompts, subscriptions, write tools, arbitrary paths, remote fetching, or network listener.
  • The compatible AI client launches the helper locally and SourceShelf reloads authorization information for every request.

No write access and no network server

The SourceShelf MCP helper cannot edit sources, delete files, fetch remote content, browse arbitrary paths, or listen for network connections. It communicates locally through a command launched by the compatible AI client.

Stopping a share or disabling MCP invalidates the copied configuration immediately.

Local or cloud-backed models remain your choice

MCP connects the desktop AI client to SourceShelf. The client may use a model running on the Mac or a cloud-backed model.

SourceShelf controls the local knowledge connection but does not control the privacy policy or data handling of the third-party AI client you choose.

Common questions

What to know before you begin

What does MCP mean?

Model Context Protocol is a standard way for compatible applications to request context and tools from another application. SourceShelf uses it for local, read-only access to an authorized knowledge pack.

Does MCP give an AI access to my whole Mac?

No. SourceShelf exposes only the immutable snapshot of the saved pack you authorize.

Can the AI change my documents?

No. SourceShelf provides no MCP write, delete, or arbitrary-file tools.

Can a cloud-backed AI client use the connection?

Potentially, when its desktop application supports the required local MCP connection. The third-party client's own privacy and data-handling terms still apply.

How do I revoke access?

Stop the individual pack share or disable Local AI Access in SourceShelf. The helper reloads authorization information for every request, so revoked access stops working immediately.
